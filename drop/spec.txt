drop v0.41 —— 一门极简语言的定义。这一页就是全部规则，读完就会写；没有别的文档。
====================================

原则
  同一件事只许有一种写法：语言不提供第二条路，也不替你决定任何东西。
  循环只有一种机制（尾递归）；转换只有一条路（写出来的那一个名字）；值不会自己变种类。

怎么切句
  一行一句，换行是唯一的语句分隔符；分号不是东西（写它是 E3），空行和缩进不参与语义。
  // 到行尾是注释，注释里的引号和括号不算数；没有块注释。
  整个文件先全部解析、再从头执行 —— 第 20 行的语法错在任何输出之前红。
  整数 = 一串十进制数字，07 就是 7；没有小数（写 1.5 是 E3），没有指数。
  字符串 = 双引号包住的一行，转义只有五个：反斜杠自身、双引号、\n、\t、
    \xHH（两个十六进制数字）。反斜杠只和紧跟它的那一个字符算一次，
    所以 "\\n" 和 "\x0D\x0A" 都是两个字符。
    串里写真实换行 = E11，要换行请写 \n。
  名字 = 字母或下划线开头（汉字算字母），后面跟字母数字下划线；大小写算不同名字。

程序：只有这三类句子
  let x = 1 + 2          绑定；重名 = 新绑定遮住旧的，已绑的不会被改动（没有赋值，x = 1 是 E3）。
                         右边只能是一个表达式。
  fn add(a, b) { a + b } 函数只有一种写法：名字 + 形参 + 块。块的值 = 最后一句，{} 的值是无。
                         没有表达式体、没有匿名函数、没有当值递的函数。
  1 + 2                  表达式单独一行 = 算它、把值丢掉，不打印任何东西。
  没有 while、没有 for、没有 break/continue —— 唯一的循环见「循环」一节。
  let 名、函数名、形参名都不能用保留名，占了是 E3。
  保留名 = 3 个关键字（let fn if）+ 8 个内置名 + 11 个「这里没有那种东西」的名字
           （while for break continue return else range map filter fold sort）。

值
  整数、字符串、true、false、无（写 none）、表 [1, "文", []] —— 就这六种，没有第七种。
  表可嵌套可混装，[] 是空表，长度不限。它们之间不自动转；比较时不同种一律 false。
  函数不是值：不能绑给别的名字、不能进表、不能比较、不能转文本，只能按名字调用；当值用了 = E3。

循环：唯一的一种
  函数在尾位调用自己 = 跳回函数开头，不涨层数，所以能一直转。
  尾位 = 函数体块里的最后一句；最后一句是 if 时，两支里的自身调用都算尾位。别处调用自己涨一层。
  非尾的自身调用同时最多叠 200 层，第 201 层进不去 = E13 —— 那是「往里缩」的上限，不是「转」的上限。
  没有第三种循环，也没有 map / filter / fold / range / sort 这些「替你循环」的名字。

> fn count(n, acc) { if(n <= 0, acc, count(n - 1, acc + 1)) }
> print(str(count(50000, 0)))
> fn last(xs) { if(len(xs) <= 1, xs[0], last(xs[1:])) }
> print(str(last([1, 2, 3])))
> fn fact(n) { if(n <= 1, 1, n * fact(n - 1)) }
> print(str(fact(10)))

表达式
  1 007 "文" true none []   字面量
  x                         名字
  add(1, 2)                 调用：只有具名函数和内置名能被调；内置名只能调用，不能当值用（let f = len 是 E3）
  xs[0]                     下标：表和字符串都行，从 0 数；越界 E6，负数下标也 E6
  xs[1:3]                   切片：左含右不含、两端可省；越界不报错，折到 0 和 len(xs)
  { let a = 1 a + 1 }       块当表达式用，值 = 最后一句
  if(c, a, b)               c 必须 true/false，只算选中的那支；写两支或四支是 E3
  (1 + 2) * 3               括号只是表达式，不是调用
  + - * / % == != < <= > >= && || ! 运算符

  a + b     两个整数相加、两个字符串拼接、或两个表拼接；混着来 = E5，不自动转
  a - b a * b a / b a % b   只吃整数，别的 = E5；/ 向零取整（-7/2 = -3），
            % 跟被除数同号（-7%2 = -1）；除数 0 = E8
  一元 -     紧跟整数、字符串、名字、) ] 之后是减法；别处（行首、= ( [ { , 与运算符后）是取负，取负只吃整数
  a == b a != b   什么都能比，不同种一律 false；表逐个元素比
  a < <= > >=     两边必须同为整数或同为字符串，否则 E5；true false none 不能比大小
  a && b a || b !a  只吃 true/false，否则 E7；左边已经定了就不算右边
  优先级从低到高、同级左结合、一元和后缀在最右：
    ||   &&   == !=   < <= > >=   + -   * / %   一元 - !   后缀 () []

作用域
  词法的：函数体能看到的名字 = 写它的那一刻能看到的（形参、外层 let、外层 fn），不看调用处。
  递归可以引用自己；前向引用别的函数只在调用时才成立。形参重名 = E12。
  块里也能定义局部函数，只在这个块里可见；它捕获定义那一刻的环境，之后再重定义外层名字也追不改它。
  调用时先把每个实参求一次值（从左到右），再绑到形参上。

转换：每样只有一条路
  str(x)     唯一的「值变文本」：整数 → "12"；true/false → "true"/"false"；none → "none"；
             字符串 → 它自己（不加引号）；表 → "[1,2]"：套方括号、元素各自 str、用 , 连，
             其中字符串元素再套引号，串里的反斜杠和双引号会被转义。
  print(s)   唯一的「写到屏幕」：只收字符串，原样这一行再补一个换行；别的种类 = E10。
             打数字写 print(str(1))：屏幕上只有 str 这一套格式规则。
  num(s)     唯一的「文本变整数」：只认「可选负号紧贴一串数字」，前后空格算别的（" -42 " = E9）；
             给它字符串以外的种类 = E10。
  bytes(s)   唯一的「文本变字节」：每个字符取其码，<=255 就是一个字节，更大的拆成 UTF-8；
             回的仍是字符串，一个字符 = 一个字节。
  len(x)     字符串的字符数、表的元素数，别的 = E5；"文" 的 len 是 1（按字符，不按字节）。
  split(s, sep)  唯一的「切开字符串」：返回字符串表，空段保留 —— split("a,,b", ",") = ["a", "", "b"]，
             split("a", ",") = ["a"]，split("", ",") = [""]；sep 或 s 不是字符串 = E10，sep 是空串 = E10。
  join(sep, xs)  用 sep 连 xs 里的字符串；元素或 sep 不是字符串 = E10；join(sep, []) = ""。
  除此之外没有第四种转换，也没有哪里会悄悄转换。
  没有 trim / abs / min / max / in / sort，没有元组、没有多个返回值 —— 排序去重自己写。

> print(str(num("42")))
> print(split("a,,b", ",")[1])
> print(str(len(bytes("文"))))
> print(str(len(bytes("\xe4"))))
> print(str(join(",", ["a", "b"])))
> print(str(["a", "b"]))
> print(str(1 == "1"))
> print(str(1 + 2 * 3))
> print(str(-7 / 2))
> print(str(1 - -1))
> print(str([1, 2, 3][1:]))
> print(str(if(1 < 2, "小", "大")))
> print(str(1 == 1 || 1 / 0 == 0))
> print(str(none))
> print(str({ let a = 1 a + 1 }))
> fn twice(x) { x * 2 }
> print(str(twice(3)))
> print("尾")

宿主：语言与外面之间只有 host 这一个口子
  host(命令, 参数)  唯一的「问外面要东西」：两个实参和返回值都是字符串（别的 = E10），命令只有七个，
              认不出 = E14：bind("") 绑到宿主起来时给的那个端口（没给 = E14），回监听句柄；
              accept(监听句柄) 阻塞等一条连接，回连接句柄；recv(连接句柄) 阻塞到至少一个字节，回
              「一字节一字符」的串，对端断了或 10 秒没动静回空串（那是断，不是错误）；
              send(句柄 + 换行 + 字节) 在第一个换行切开，换行后面一个字符发一个字节；
              peer(连接句柄) 回 "IP:端口"；close(句柄) 之后那个句柄就发不出东西；date("") 回时钟。
              句柄是字符串，语言不认识它指什么；阻塞、超时、断归宿主，不占错误码。
  语言不认识「请求」，那是用 drop 写的一个库的事；库没有专门的语法。
  跑法只有一条：python3 drop.py [--port <端口>] 库.dr 程序.dr —— 宿主按这个顺序并起来。

出错
  一红就停：打印一行「挂：第 N 行 Ex —— 中文说明」到 stderr，退出码 1，后面的语句不再执行。
  没有警告、没有堆栈、没有半个输出；文件读不到、命令行用错也是一行「挂：…」，不是 Python 的 Traceback。
  N 是那个记号所在的行；两处例外：函数体里的错报在调用那一行，表字面量里的错报在 [ 那一行。
  Ex 就是「哪个」：14 个码对 14 类原因，没有第二种解释。形状不对一律 E3：怪符号、少括号少逗号、
  函数体写法不对、占了保留名、用了别的转义字符、if 支数不对。
  E11 是「话说到一半」：引号或括号没闭合，文件或一句没头没尾。
  错误一共 14 种，穷举如下：
    E1  没绑过的名字      E2  参数个数不符    E3  语法错
    E4  不是函数不能调用  E5  值种类不对      E6  下标越界
    E7  条件不是 true/false  E8  除数为 0    E9  该是整数的地方不是
    E10 该是字符串的地方不是  E11 话说到一半  E12 形参重名
    E13 调用叠到第 201 层  E14 宿主不肯做
  输出只有一条规则：只有 print 产生输出，一次一行，程序结束时不会自动打任何东西。
