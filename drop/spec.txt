drop —— 一门极简语言的定义。这一页就是全部规则，读完就会写；没有别的文档。
========================================================================

怎么切句
  一行一句，换行是唯一的语句分隔符；行尾分号不算东西，空行和缩进不参与语义。
  // 到行尾是注释，注释里的引号和括号不算数；没有块注释。
  整个文件先全部解析、再从头执行 —— 第 20 行的语法错会在任何输出之前红。
  词法：
    整数 = 一串十进制数字，07 就是 7。没有小数（写 1.5 是 E3），没有指数。
    字符串 = 双引号包住的一行，\\ \" \n \t 四种转义参与语义 —— 反斜杠只和紧跟它的那一个字符算一次，
      所以 "\\n" 是两个字符：反斜杠和 n；
      串里写真实换行 = E11，要换行请写 \n。
    名字 = 字母或下划线开头（汉字算字母），后面跟字母数字下划线；大小写算不同名字。

程序
  一行只能是这三类之一：let 绑定、fn 定义、一个表达式。
  let x = 1 + 2                 绑定一个值；重名 = 新绑定遮住旧的，已绑的不会被改动。
                                顶层没有裸赋值，x = 1 是 E3。右边只能是一个表达式。
  fn add(a, b) = a + b          定义函数，表达式的值就是返回值
  fn show(x) { print(x) x }     或者用块：一句接一句，块的值 = 最后一句，{} 的值是无
  fn(x) = x + 1                 匿名函数，只能带表达式体；要写块就用具名的
  一个表达式单独占一行 = 算它、把值丢掉；顶层这样写不打印任何东西。
  let 的名字、函数名、形参名都不能用内置名或关键字（let fn if true false none 加那 10 个内置函数），占了是 E3。
  名字必须先绑定再问它要值。一个名字代表哪个东西：能写成 let x、fn f 的才叫名字。

值
  整数、字符串、true、false、无（写 none）、表 [1, "文", []]。
  就这六种，没有第七种，它们之间不自动转。表可嵌套可混装，[] 是空表，长度不限。
  函数也是值：可以 let f = len、可以当参数递给 map、可以放进表里再取出来调用。

表达式
  1 007 "文" true none [1, 2] fn(x) = x + 1   字面量
  x                                            名字
  add(1, 2)                                    调用：名字、内置、表元素、if 选出来的，都能调
  xs[0]                                        取下标：表和字符串都行，从 0 数；越界 E6，负数下标也 E6
  xs[1:3]                                      切片：左含右不含，两端可省；越界不报错，折到 0 和 len(xs)
  { let a = 1 a + 1 }                          块当表达式用，值 = 最后一句
  if(c, a, b)                                  条件：c 必须 true/false，只算选中的那支
  (1 + 2) * 3                                  括号只是表达式，不是调用
  + - * / % == != < <= > >= && || !            运算

  a + b            两个整数相加、两个字符串拼接、或两个表拼接；混着来 = E5
  a - b  a * b  a / b  a % b   只吃整数，别的 = E5；/ 向零取整（-7/2 = -3），
                     % 跟被除数同号（-7%2 = -1）；除数 0 = E8
  一元 -            看它左边：紧跟在整数、字符串、名字、) ] 之后是减法，
                   其余位置（行首、= ( [ { , 和别的运算符之后）是取负，只吃整数
  a == b  a != b   什么都能比，不同种一律 false；表逐个元素比；函数之间 == 比不出真假 = E5
  a < b <= > >=    两边必须同为整数或同为字符串，否则 E5；true false none 不能比大小
  a && b  a || b   只吃 true/false，否则 E7；左边已经定了就不算右边
  !a               只吃 true/false，否则 E7

  优先级从低到高，同级左结合，一元和后缀在最右：
    ||   &&   == !=   < <= > >=   + -   * / %   一元 - !   后缀 () []

> print({ let a = 1 a + 1 })
> let add = fn(x) = x + 1
> print(add(1))
> let g = add
> print(g(1))
> print([add, g][0](1))
> let h = if(true, len, print)
> print(h("ab"))

作用域与函数
  词法的：函数体和匿名函数能看到的是它被写在那儿时能看到的名字（形参、外层 let、外层 fn），
  不看调用处。递归可以引用自己；前向引用别的函数只在调用时才成立。
  块里也能定义局部函数，只在这个块里可见。
  调用时先把每个实参求一次值（求值顺序从左到右），再绑到形参上。

内置函数只有 10 个，外加 let、fn、if 三个关键字 —— 一共 13 个名字，没有别的：
  print(x)      只收 1 个值：先按 str(x) 转成文本，再打这一行。返回值是无。
  str(x)        转成字符串：整数→"12"、true/false→"true"/"false"、无→"none"、
                字符串→它自己（不加引号）；
                表→"[1,2]"：外面套方括号，元素各自 str，用 , 连，
                  其中的字符串元素外面要再套引号，串里的 \\ 和 " 会被转义
                  —— 所以 ["a,b"] 打得出来是 ["a,b"]，跟 ["a","b"] 分得开。
                函数不能转文本 = E5
  num(s)        只认「可选正负号紧贴一串数字」，前后空格也算别的东西（" -42 " = E9）；
                其余写法 = E9；给它整数或别的种类 = E10
  len(x)        字符串的字符数、表的元素数；别的 = E5。"文" 的 len 是 1（按字符，不按字节）
  range(n)      整数 → [0, 1, .., n-1]；n 不是整数 = E9；n 不大于 0 得空表
  map(f, xs)    对表的每个元素调一次 f(x)，返回结果组成的表；f 收 1 值
  filter(f, xs) 只留下 f(x) 为 true 的元素；f 回了不是 true/false 的东西 = E7
  fold(f, xs, z) 从左折：f(f(f(z, x0), x1), x2)；f 收 2 值；xs 是空表就返回 z
  sort(xs)      返回新表：元素必须全整数或全字符串，混了或夹了别的 = E5；sort([]) = []
  join(sep, xs) 用 sep 把 xs 里的字符串连成一个串；元素或 sep 不是字符串 = E10；
                join(sep, []) = ""
  map filter fold 的第一个参数必须是函数（不是 = E4），第二个必须是表（不是 = E5）；
  这三个不吃字符串 —— 想按字符处理就先自己把串切成表。
  没有 split、trim、abs、min、max、in，没有元组、没有多个返回值；要就用上面这些自己写。

输出
  只有 print 产生输出，一行一个值；程序结束时不会自动打任何东西。

运行
  python3 drop.py 程序.dr
  函数调用同时最多叠 200 层：第 201 层进不去 = E13。

出错
  一红就停：打印一行「挂：第 N 行 Ex —— 中文说明」到 stderr，退出码 1，后面的语句不再执行。
  没有警告、没有堆栈、没有半个输出；文件读不到、命令行用错同样是一行「挂：…」，不是 Python 的 Traceback。
  N 是那个记号所在的行；两处例外：函数体里的错报在调用那一行，表字面量里的错报在 [ 那一行。
  Ex 就是「哪个」：13 个码对 13 类原因，没有第二种解释。形状不对的写法一律归 E3：怪符号、
  注释外的怪字符、少括号少逗号、函数体写法不对、名字占了内置名、转义用了别的字符、if 的支数不对。
  E11 是「话说到一半」：引号或括号没闭合，文件或一句没头没尾。
  错误一共 13 种，穷举如下：
    E1  没绑过的名字          E2  参数个数不符        E3  语法错
    E4  不是函数不能调用      E5  值种类不对          E6  下标越界
    E7  条件不是 true/false   E8  除数为 0            E9  该是整数的地方不是
    E10 该是字符串的地方不是  E11 话说到一半          E12 形参重名
    E13 调用叠到第 201 层
  没有第 14 种：跑不完的情况由最后一条接住，宿主栈崩不算实现的一部分。
